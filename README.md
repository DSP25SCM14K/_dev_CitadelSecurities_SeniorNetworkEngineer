# Dev Kumar — Networks under pressure

A responsive portfolio for Dev Kumar, focused on resilient low-latency trading networks, market data, automation, and exchange connectivity.

## Publish

This static site is deployed to GitHub Pages through GitHub Actions on each push to `main` and on manual workflow runs. The repository root is the published site; no build step is required.

## Local preview

Open `index.html` in a browser or serve this folder with any static file server. The animated market network illustration is local SVG, and motion effects honor reduced-motion preferences.
